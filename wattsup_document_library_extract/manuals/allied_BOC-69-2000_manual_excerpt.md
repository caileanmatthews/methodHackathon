# Allied Switchgear Corp. — Instruction Book IB-BOC-69-2000 (Rev. A, 1986)
## Outdoor Bulk Oil Circuit Breaker, Type BOC-69-2000 (2000 A), with SM-4 Spring Operating Mechanism

> Scanned copy from Watt's Up document library. Filed in the same binder folder as IB-BOC-69.

---

### Page 1-1 — Scope
This instruction book covers the BOC-69-2000, rated 72.5 kV, **2000 A continuous**, equipped with the heavier SM-4 spring operating mechanism. For 1200 A breakers with the SM-3 mechanism, refer to IB-BOC-69.

---

### Page 4-6 — Trip Latch Adjustment (SM-4)
Latch engagement shall be **0.045 to 0.070 inch**. Adjust with the eccentric latch stop; no locknut is used on the SM-4.

---

### Page 4-8 — Lubrication (SM-4)
Lubricate trip latch, roller, and main pivot every 5 years or 2,500 operations. Use ASC G-11.

---

### Page 4-13 — Cold Weather Operation (SM-4)
At ambient temperatures below 0°F (-18°C), opening times up to 3.5 cycles are acceptable on the SM-4 provided the minimum trip voltage test is passed. Verify both heaters are energized.

---

### Page 6-1 — Tests and Acceptance Values (BOC-69-2000)

| Test | Acceptance value |
|---|---|
| Opening time, rated control voltage | 2.5 cycles maximum (above 0°F) |
| Trip coil resistance at 77°F | 8.0 ohms ±10% |
| Contact resistance, per pole | 200 micro-ohms maximum |
